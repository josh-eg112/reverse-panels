# Changelog

## 1.0 (1), Beta 1

First public beta.

- Kavita, OPDS, Nextcloud, iCloud Drive, and on-device libraries.
- CBZ, CBR, and PDF reading, with full-page and Panel Flow modes, including right-to-left.
- On-device panel detection model, on by default (Settings → Experimental → Model Panel Detection).
- Offline downloads, Continue Reading, Favorites, and pinned library locations.

Known limitations:
- Sideload only. Free Apple ID installs must be refreshed every 7 days.
- Remote servers should use HTTPS.
